## 3. WCAG 2.1 适老化标准 (国际)

### 3.1 三级合规
- **Level A**: 最低 (4 原则: 可感知/可操作/可理解/健壮)
- **Level AA**: 推荐 (含 1.4.3 对比度 ≥ 4.5:1, 1.4.4 文字缩放, 2.4.7 焦点可见)
- **Level AAA**: 最高 (对比度 ≥ 7:1, 1.4.6 增强)

### 3.2 适老化关键 8 指标
| 指标 | AA 标准 | 实操建议 |
|------|--------|---------|
| 字体大小 | ≥ 18pt 或 14pt bold | 默认 20pt,可调 200% |
| 文字对比度 | ≥ 4.5:1 | 深色文字 + 浅色背景 |
| 大文字对比度 | ≥ 3:1 | 标题用 24pt+ |
| 目标尺寸 | ≥ 44×44 CSS px | 按钮 60px+ |
| 时间限制 | 可关闭/调整 | 默认无超时 |
| 闪烁 | ≤ 3 次/秒 | 避免动效 |
| 输入目的 | 可编程确定 | autocomplete |
| 错误识别 | 自动检测+描述 | 高亮+文字说明 |

### 3.3 GB/T 45272—2025 适老化设计指南
- 2025.9.1 实施
- 4 大方向: 安全性/易用性/舒适性/智能化
- 鼓励: 远程监控/健康监测/紧急呼叫
- 简化操作/降低难度/避免误操作

## 5. 适老化 6 大设计原则

### 5.1 视觉 (Visual)
- **大字体**: 默认 20pt,可缩放至 200%
- **高对比度**: 黑/白/深色背景,避免灰色文字
- **清晰图标**: 实物照片而非抽象图形
- **减少动效**: 避免 1 秒内闪烁 > 3 次
- **大按钮**: 60px+ 触摸目标

### 5.2 听觉 (Auditory)
- **清晰发音**: 老人高频听力下降,中频优先
- **慢速语音**: TTS 0.8x 或 0.9x
- **视觉辅助**: 语音+字幕同步
- **可调音量**: 系统级独立控制
- **降噪**: 减少背景音

### 5.3 认知 (Cognitive)
- **简化语言**: 避免 jargon,口语化
- **多步骤分解**: 复杂操作拆成 3 步内
- **过程性反馈**: 实时鼓励,避免单次失败
- **避免数字罗列**: 文字+语音双通道
- **重复确认**: 重要操作二次确认

### 5.4 物理 (Physical)
- **大目标**: 按钮/链接 ≥ 60px
- **容错率高**: 误操作可撤销
- **少滚动**: 关键信息一屏内
- **手势宽容**: 简单点击/滑动,避免复杂手势
- **可暂停**: 长任务支持断点

### 5.5 情感 (Emotional)
- **鼓励式评价**: 强调进步,弱化错误
- **陪伴感**: 真人老师/AI 班主任
- **社群归属**: 同龄人圈子
- **避免挫败**: 难度递进而非跳跃
- **正向激励**: 完成里程碑有奖励

### 5.6 学习 (Learning)
- **小颗粒度**: 每次 5-10 分钟
- **高频反馈**: 每个练习都有回应
- **重复巩固**: 重点内容多轮复习
- **生活化案例**: 用老人熟悉的内容教学
- **成就可视化**: 进度条+勋章系统

## 6. CoPiano 现状 + 银发空白

### 6.1 已有
- `voice_dialog.py` 实时语音对话 (ASR + TTS + LLM)
- `tts_edge.py` Edge-TTS 支持多语言 + 8 声音
- `teaching_engine.py` 6 个直答 + LLM 上下文
- `student_db.py` 长期记忆
- `curriculum.py` 7 天自适应课程

### 6.2 银发空白
- **TTS 无慢速档**: 1.0x 默认,老人嫌快
- **LLM prompt 复杂**: 含专业术语,理解门槛高
- **无语音放大**: 老人听力下降
- **无大字反馈**: 文字反馈密密麻麻
- **无鼓励式评价**: 反馈偏专业/纠错
- **无 3 步操作**: 一些流程超过 3 步

### 6.3 CoPiano 银发模式差异化
- **轻量级**: 1 行命令 `senior_mode on` 切换
- **本地化**: 中文/方言优先
- **LLM prompt 优化**: "30 年教学经验的张老师" 人设
- **TTS 慢速档**: zh-CN-XiaoyiNeural speed=0.85
- **自动检测**: 用户年龄字段 (student_db 已有) → 自动切档
- **零学习成本**: 默认开启 + 提示音

## 7. Cycle 5 stage 2 实施目标

### 7.1 模块: `scripts/senior_mode.py`

### 7.2 4 大开关
1. **TTS 慢速** (speed 0.85, pitch 不变, volume +20%)
2. **LLM 简化 prompt** (鼓励式 + 通俗 + 短句)
3. **超时延长** (VAD 1.5s → 3s,对话间隔 5s → 10s)
4. **大字反馈** (终端字号放大 + 简化输出)

### 7.3 voice_dialog 集成
- `set_senior_mode(True)` 全局开关
- 关键词识别 "长辈模式/老年模式/慢一点/senior mode"
- student_db 自动按年龄切档 (>= 60 自动开)

### 7.4 测试场景
1. 正常模式 (默认)
2. 银发模式 (主动开)
3. 自动银发 (60+ 学生)
4. 银发 + 教学对话 (验证 prompt 简化)

## 9. 风险与依赖

| 风险 | 缓解 |
|------|------|
| 老人不会切档 | 语音命令"开启长辈模式" + 自动按年龄 |
| LLM 慢响应 | 银发 prompt 长度减半 (5s → 2.5s) |
| TTS 不自然 | Edge-TTS XiaoyiNeural 已是最佳中文女声 |
| 隐私顾虑 | 全部本地处理,不上传 |
| 鼓励式反成"虚假" | LLM 自我评 (specificity + supportive) 监控 |
